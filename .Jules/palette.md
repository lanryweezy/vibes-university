## 2024-05-18 - Input Wrapper Inline Icons Override
**Learning:** The application uses global CSS that absolutely positions icons inside `.input-wrapper`. When adding interactive elements like a toggle button inside this wrapper, nesting another `<i>` tag causes its layout to break if the global CSS isn't explicitly overridden.
**Action:** When adding nested FontAwesome icons inside `.input-wrapper` (like in a toggle button), explicitly add `style="position: static; transform: none;"` to the nested icon to prevent it from inheriting the global absolute positioning meant for the static input prefix icon.
